## Persistência

Para G1 foi usado SQLite em arquivo efêmero de QA e filesystem separado para binários.

Essa escolha é deliberadamente limitada ao gate de fundação. A arquitetura continua apontando para SQL Server/Azure SQL na fronteira que precisa provar tenancy e segurança em SQL real.

## Falhas encontradas durante a execução

A primeira rodada de CI identificou:

- sintaxe TypeScript incompatível com `erasableSyntaxOnly`;
- matcher TypeScript inadequado;
- string C# de teste mal escapada;
- versão transitiva vulnerável de `SQLitePCLRaw.lib.e_sqlite3`.

Correções:

- classe `ApiError` passou a declarar campos explicitamente;
- matcher simplificado;
- strings C# corrigidas;
- `SQLitePCLRaw.bundle_e_sqlite3` fixado em 2.1.13.

A rodada seguinte encontrou que a configuração QA era resolvida cedo demais para o override do `WebApplicationFactory`. A leitura foi movida para depois do build da aplicação.
